# 3. Login (if required)
Username: admin
Password: admin123

# 4. Start editing!

### Editing Workflow
```
1. Click page button → [Home] [Shop] [About] [Contact]
2. Hover over text → See border + tooltip
3. Click text → Jump to field in editor
4. Edit content → See orange dot (●)
5. Click "Save Changes" → Updates Firebase
6. Preview refreshes → See changes
```

### Multi-Language
