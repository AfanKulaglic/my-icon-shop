## 💡 Icon Format

Icons use the format: `collection:icon-name`

**Examples:**
```
mdi:home
lucide:heart
heroicons:star
fa6-solid:user
tabler:settings
```

## 🔍 Finding Icons

### Method 1: Icon Picker (Easiest)
1. Click "Browse Icons" in admin
2. Search by keyword
3. Select from grid
4. Done!

### Method 2: Iconify Website
1. Visit: https://icon-sets.iconify.design/
2. Search for icon
3. Copy name (e.g., `mdi:home`)
4. Paste in admin

### Method 3: Type Directly
Just type the icon name in the field:
```
mdi:rocket
lucide:coffee
fa6-brands:github
```
